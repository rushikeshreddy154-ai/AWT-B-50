# Student Registration Form

## Project Description

This project is a simple Student Registration Form developed using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Student Name
- Roll Number
- Email
- Age
- Course Selection
- Form Validation
- Registration Success Message

## How to Run

1. Open the index.html file.
2. It will open in a web browser.
3. Fill in the registration form.
4. Click the Register button.
